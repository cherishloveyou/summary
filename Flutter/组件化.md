# **Flutter组件化**

> #### 组件化格式

- 通过Dart包：纯`Flutter`  flutter create --template=package my_dart_package
- 通过Plugin插件：如果组件不仅仅是 UI 组件，还涉及到与平台（如 Android 和 iOS）的交互，你可以使用 Flutter 的插件机制，将组件和平台代码一起封装成一个插件包。（flutter create --template=plugin --platforms android,ios my_plugin）

> #### 组件化依赖方式
